llm-shape-detector / portal

Detect LLM/AI usage from the shape of traffic: packet timing and sizes only. No hostname, SNI, IP, or port is ever a feature, so it survives Encrypted Client Hello.
The tell: an LLM streaming response is one long-lived TCP connection that dribbles many small downstream packets over several seconds, token by token. A page load is one big burst; a REST call is a short request/response. We classify on that trickle shape. There is no identifier left to encrypt, so ECH doesn't blind it.

OpenAI-compatible works with OpenAI, Groq, OpenRouter, Together, LM Studio, vLLM, and the Vercel AI Gateway.
We make a real streaming call, measure each token's true arrival time and size, then reconstruct the on-wire flow and detect it. No raw packet capture, so no driver is needed.
No API key needed. Builds synthetic flows and runs the real tshark and model pipeline.
The model sees only shape features from your capture. IP and port are read solely to split flow directions.
Metadata-only by design: it never decrypts, reassembles payloads, or resolves names. IP and port are used only to split each flow into upstream and downstream directions; their values never reach the model.
